# 需求文档：HugeGraph-LLM SDK 首期解耦

用户已通过四轮问答确认边界，并明确要求实施完整计划；开发、测试、调研和 review 并行推进。

用户最终确认发行名 `hugegraph-llm-sdk`、导入名 `hugegraph_llm_sdk`，对外称 HugeGraph-LLM SDK。该名称为后续更多可灵活调用的 LLM 能力保留空间，首期交付仍限于图设计与抽取，不扩大本次功能范围。

## 已确认的用户需求

| 编号 | 用户故事与验收标准 |
| --- | --- |
| U1 | 独立 Python 项目可以只安装 SDK，在没有 Gradio、FastAPI、pycgraph、HugeGraph 客户端和模型厂商 SDK 的情况下，注入模型完成图设计与抽取。 |
| U2 | SDK 保持 HugeGraph 属性图 schema、类型和 ID 语义；设计、校验和抽取不连接数据库。 |
| U3 | SDK 配置通过参数注入；同进程不同模型、prompt、schema 互不影响，不读写应用配置或修改全局日志。 |
| E1 | 输入样本文本、业务问题和可选 schema 示例时，返回 schema 草案及结构化校验问题；业务方可以修改并再次校验。 |
| E2 | 输入文本或已分块文本与合法 schema 时，默认执行抽取、校验、最多 2 次审阅及 1 次修复，返回有序块结果。 |
| O1 | 显式关闭审阅时，只抽取与本地校验，通过状态为 validated；审阅通过状态为 final。 |
| X1 | 参数或 schema 无效时，在模型调用前报错；块级失败保留为结果，不丢弃其他块的产出。 |
| U4 | 同步和原生异步接口均可用；同步模型可通过显式线程适配器接入异步系统。 |
| U5 | 默认并发为 1；提高并发时由无参模型工厂为每块建立独立实例；异步取消向上传播。 |
| O2 | 用户可以替换模型、prompt、校验器以及 bundle 中的单个步骤；基础使用只需要完整流程入口。 |
| U6 | 同仓库独立 SDK 维护一份共享业务实现；旧 UI、HTTP 和配置文件使用方式保持兼容。 |
| U7 | SDK wheel 在工作区之外验证 Python 3.10–3.13；旧应用继续使用其原有版本范围。 |

## 首期明确不包含

- 图召回、写库、索引刷新、跨块实体消歧和语义合并。
- PDF、DOCX、网页解析，设计会话、版本管理、持久化任务与断点续跑。
- 完整旧 HTTP 服务的无 UI 启动改造；本期保证 SDK 安装、导入和运行独立。
- 自动对外发布包或部署服务。

## 兼容边界

保留旧 UI 主要操作、HTTP 合同和配置文件用法；内部 Python 接口允许整理。新 SDK 默认启用审阅且默认并发为 1，不改变旧入口的开关、并发默认或响应结构。
